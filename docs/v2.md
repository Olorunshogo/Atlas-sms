# Atlas-sms — V2 Scope

Deliberately deferred out of V1. Nothing below gets built until V1 (single
store, POS + payments + inventory + offline) has shipped and hit its
onboarding/support targets, per the PRD's sequencing. Logged here so it
doesn't get silently picked up early or forgotten later.

## Multi-store roles and access

- `store_group_grants` — cross-store access for a role grant without a full
  tenant-wide (`store_id NULL`) grant. The "regional manager over 3 of my 5
  stores" case.
- Any admin UI for assigning/editing store groups.

## Multi-store operations

- Stock transfers between stores.
- Cross-store reporting and comparisons (takings, margin, staff performance
  across branches).
- Tenant Admin's multi-location dashboard view.

## Possible later (not committed, not scoped)

- `tenants.parent_tenant_id` — a real franchise/holding-company hierarchy

  franchise/holding-company need shows up; nothing in the PRD asks for this
  today. Deliberately not built pre-emptively per the store README's
  warning against over-engineering variation that hasn't shown up yet.
